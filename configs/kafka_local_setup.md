# Локальный запуск Apache Kafka 4.3.1 на Ubuntu (Режим KRaft с постоянным Cluster ID)

Инструкция по настройке и запуску Apache Kafka версии 4.x в автономном локальном режиме без использования ZooKeeper. Идентификатор кластера сохраняется в файл, что позволяет при необходимости переинициализировать хранилище с тем же ID.

## Предварительные требования

Для работы Kafka требуется **Java 11 или выше** (в данном примере используется Java 17).  
Проверить версию Java можно командой:
```bash
java -version
```

## Шаг 1: Переход в директорию Kafka

Откройте терминал и перейдите в рабочую папку Kafka:
```bash
cd /opt/kafka_2.13-4.3.1
```

## Шаг 2: Генерация и сохранение ID кластера в файл

Чтобы не терять ID кластера и не генерировать его заново при каждой очистке логов, запишем его в файл `cluster_id.txt`:
```bash
bin/kafka-storage.sh random-uuid > cluster_id.txt
```

## Шаг 3: Форматирование директории хранения данных

Инициализируйте конфигурацию хранилища, подставив ID из созданного файла. Для локального запуска в Kafka 4.x обязательно используется флаг `--standalone`:
```bash
bin/kafka-storage.sh format --standalone -t $(cat cluster_id.txt) -c config/server.properties
```

## Шаг 4: Запуск сервера Kafka

Запустите брокер Kafka. При самом запуске передавать ID не нужно — сервер автоматически считает его из настроек, созданных на этапе форматирования.

*Примечание: Оставьте это окно терминала открытым. Принудительное закрытие или нажатие `Ctrl + C` остановит сервер.*

```bash
bin/kafka-server-start.sh config/server.properties
```
После успешного старта брокер будет доступен по адресу `localhost:9092`.

---

## Шаг 5: Проверка работы (В новом окне терминала)

Откройте **новое окно или вкладку терминала**, вернитесь в рабочую директорию (`cd /opt/kafka_2.13-4.3.1`) и выполните следующие команды для проверки:

### 1. Создание тестового топика
```bash
bin/kafka-topics.sh --create --topic my-local-topic --bootstrap-server localhost:9092
```

### 2. Запуск продюсера (Отправка сообщений)
```bash
bin/kafka-console-producer.sh --topic my-local-topic --bootstrap-server localhost:9092
```
*Введите любое сообщение в консоли (например, `Hello Kafka`) и нажмите **Enter**. Для выхода нажмите **Ctrl + C**.*

### 3. Запуск консьюмера (Чтение сообщений)
Чтобы увидеть отправленные сообщения, откройте еще одно окно терминала и запустите:
```bash
bin/kafka-console-consumer.sh --topic my-local-topic --from-beginning --bootstrap-server localhost:9092
```

## Шаг 6: Создание default топика
```bash
bin/kafka-topics.sh --create --topic some.svc.group.topic.name --bootstrap-server localhost:9092
```
